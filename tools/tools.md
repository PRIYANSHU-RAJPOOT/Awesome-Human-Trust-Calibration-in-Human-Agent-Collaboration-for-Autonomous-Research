# Tools and Libraries

This page contains useful tools and libraries related to human–AI interaction, explainable AI, autonomous agents, uncertainty, and AI-assisted research.

## 1. SHAP

**Purpose:** SHAP is a library for explaining the predictions of machine learning models.

**Relevance:** Explainability can help users understand why an AI system produced a particular output. This is relevant to trust calibration because explanations may influence human reliance on AI.

[Official Project](https://shap.readthedocs.io/)

## 2. LIME

**Purpose:** LIME provides local explanations for predictions made by machine learning models.

**Relevance:** It can be used to study how explanations affect human understanding, trust, and reliance on AI systems.

[Official Project](https://github.com/marcotcr/lime)

## 3. LangChain

**Purpose:** LangChain provides tools and components for building applications using large language models and AI agents.

**Relevance:** It can be used to develop autonomous or semi-autonomous agents that perform multi-step tasks, making it useful for experiments involving human oversight and trust calibration.

[Official Project](https://www.langchain.com/)

## 4. Hugging Face Transformers

**Purpose:** A widely used library for working with transformer-based machine learning models.

**Relevance:** Researchers can use transformer models to develop and evaluate AI systems that humans interact with during trust and reliance experiments.

[Official Project](https://huggingface.co/docs/transformers/)

## 5. MLflow

**Purpose:** MLflow supports experiment tracking, model management, and reproducibility.

**Relevance:** Tracking AI performance over time can help researchers study whether human trust corresponds appropriately to demonstrated system reliability.

[Official Project](https://mlflow.org/)

## 6. OpenAI Evals

**Purpose:** OpenAI Evals provides a framework for evaluating AI system performance.

**Relevance:** Reliable evaluation is important for trust calibration because users need evidence about an AI system's capabilities and limitations.

[Official Project](https://github.com/openai/evals)

## Why These Tools Matter

Trust calibration requires more than simply building an AI system. Researchers need tools to:

* Measure and explain AI behavior
* Evaluate reliability and performance
* Build autonomous or agentic workflows
* Track experiments
* Identify limitations and uncertainty
* Support transparency and human oversight
