# GitHub Implementations

This page lists open-source implementations relevant to explainable AI, autonomous agents, AI evaluation, and human oversight.

## 1. SHAP

**Repository:** SHAP

**What it implements:** A Python library for explaining machine learning model predictions using Shapley values.

**Why it is relevant:** Explainability can influence whether users appropriately trust AI decisions.

[View Repository](https://github.com/shap/shap)

## 2. LIME

**Repository:** LIME

**What it implements:** Local explanations for individual predictions made by machine learning models.

**Why it is relevant:** It can support experiments investigating how AI explanations influence human trust and reliance.

[View Repository](https://github.com/marcotcr/lime)

## 3. LangChain

**Repository:** LangChain

**What it implements:** Frameworks and tools for building applications and workflows using large language models and AI agents.

**Why it is relevant:** Autonomous and agentic workflows provide a practical environment for studying human oversight, delegation, and trust calibration.

[View Repository](https://github.com/langchain-ai/langchain)

## 4. AutoGPT

**Repository:** AutoGPT

**What it implements:** An open-source autonomous AI agent platform designed to perform multi-step tasks.

**Why it is relevant:** Autonomous agents provide a direct example of systems where humans must decide when to trust, supervise, or intervene.

[View Repository](https://github.com/Significant-Gravitas/AutoGPT)

## 5. Microsoft AutoGen

**Repository:** AutoGen

**What it implements:** A framework for building multi-agent AI applications and coordinating interactions between AI agents and humans.

**Why it is relevant:** Multi-agent systems provide an environment for studying collaboration, delegation, communication, and human oversight.

[View Repository](https://github.com/microsoft/autogen)

## 6. OpenAI Evals

**Repository:** OpenAI Evals

**What it implements:** A framework for evaluating and testing AI system performance.

**Why it is relevant:** Trust calibration depends on understanding the actual capabilities and limitations of an AI system.

[View Repository](https://github.com/openai/evals)

## Selection Criteria

The repositories in this collection were selected based on their relevance to one or more of the following areas:

* Human–AI interaction
* AI explainability
* Autonomous agents
* Multi-agent systems
* AI evaluation
* Transparency
* Human oversight
* Appropriate reliance and trust calibration

When selecting an implementation, researchers should also consider documentation quality, source-code availability, maintenance, reproducibility, licensing, and its connection to recognized research or projects.
